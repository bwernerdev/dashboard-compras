# src/styles — CSS em camadas

| Arquivo | Conteúdo |
|---|---|
| `tokens.css` | Todos os tokens (cores, tipografia, espaço, raio, sombra) e o tema escuro (`html[data-theme="dark"]`, só redefine tokens). Inclui a paleta dos gráficos (`--serie-1..7`, validada) e os status `--st-bom`/`--st-critico` (só SLA) |
| `base.css` | Reset, topo (botões só com ícone: `botao-icone`), abas, faixa de filtros (fixa ao rolar), topo fixo e compacto ao rolar (`html.topo-compacto`), página, grades (`grade-2`, `grade-2-3`, `pilha`), utilitários (`so-leitor`, `so-impressao`, `texto-fraco`) |
| `componentes.css` | Botões, campos, menu de ações (`menu`, `menu-painel`, `menu-item`), chip, alternador, cartões, blocos, filtros, gráficos, dica, selos de SLA, tabela, diálogos, caixas de importação, densidade compacta, painel de detalhe (`detalhe-sc`), mini gráfico dos cartões (`cartao-serie`), barras com gradiente e animação `crescer`, colunas verticais (`grafico-colunas`), tabela de gráfico recolhida (`tabela-recolhivel`), contador e "×" dos filtros, tela apagada ao redesenhar (`atualizando`). Faixa alternada: `--zebra` nas tabelas simples, `--zebra-grupo` (mais forte) nas agrupadas por SC/OF |
| `impressao.css` | Botão "Imprimir": A4 deitado, sem controles, filtros ativos em texto no topo (o app troca para o tema claro ao imprimir) |
